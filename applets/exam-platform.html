A self-contained exam platform for multiple-choice and written questions. Load a question file, answer at your own pace, and get a detailed results report you can hand to an AI for marking and explanation.

How it works
01
Prepare a JSON file
Write your questions in the JSON format described below, or ask an AI to generate them for you. Save with a .json extension.
02
Load & answer
Drop your file below. Questions appear in order with shuffled options. Navigate freely with Previous / Next or jump via the question palette.
03
Flag anything uncertain
Use the Flag for review checkbox on any question — even ones you answered. Flagging opens a box where you can type a note or a specific question, which is included in your results file.
04
Review & download
Submit to see your score and a full comparison table. Download a .txt results file pre-formatted to paste into an AI for explanations.

JSON file format

Your file must be a .json file containing a single array of question objects. Each object has exactly three fields:

questionThe question text shown to the user.
optionsAn array of answer choices (minimum 2, no upper limit — supports True/False up to 26 options).
answerThe correct answer. Must match one entry in options exactly — same capitalization, spacing, and punctuation.
Standard multiple choice
[
  {
    "question": "What does DNS stand for?",
    "options": [
      "Domain Name System",
      "Data Network Service",
      "Dynamic Node Server",
      "Distributed Name Service"
    ],
    "answer": "Domain Name System"
  }
]
True / False
[
  {
    "question": "IPv6 addresses are 128 bits long.",
    "options": ["True", "False"],
    "answer": "True"
  }
]
More than 4 options
[
  {
    "question": "Which OSI layer is responsible for routing packets between networks?",
    "options": [
      "Physical", "Data Link", "Network",
      "Transport", "Session", "Presentation", "Application"
    ],
    "answer": "Network"
  }
]
Long / written answer (not auto-marked)
[
  {
    "question": "Explain the difference between authentication and authorization.",
    "type": "long"
  },
  {
    "question": "Write a Django ORM query to get all students named Alice.",
    "type": "long",
    "answer": "Student.objects.filter(name='Alice')"
  }
]
Code inside a question
[
  {
    "question": "What is wrong with this view?\n\n```python\ndef student_list(request):\n    qs = Student.objects.all()\n    return render(request, \"list.html\", {\"student\": qs})\n```",
    "options": [
      "The context key should be `students`",
      "`all()` returns nothing",
      "`render()` needs a fourth argument"
    ],
    "answer": "The context key should be `students`"
  }
]
💻Wrap code in triple backticks (optionally with a language, e.g. ```python) to render it as a formatted code block, and single backticks for `inline code`. Works in questions, options, and answers. Inside JSON, newlines must be written as \n and any double quotes escaped as \".
✎A question is treated as written / long-answer if it has "type": "long" or simply no options field. It shows a text box instead of choices, is not auto-marked, and your typed response is captured in the downloadable results for an AI (or you) to mark. The answer field is optional here — include it as a reference/model answer if you like.
⌨Written questions have Prose and Code editor modes (switchable at any time). Code mode gives you a line-number gutter, Tab / Shift+Tab indenting, auto-indent after : or an open bracket, and auto-closing brackets and quotes. The mode is auto-detected from the question, or you can force it with "mode": "code" or "mode": "prose".
⚠For multiple-choice questions, the answer value must be character-for-character identical to its matching entry in options. The file will be rejected if they do not match exactly.
💡Question numbers (Q1, Q2…) are assigned by position in the array. Keep this in mind when cross-referencing an answer key.
💡You can ask an AI to generate a question file. Paste your notes and say: "Generate 20 MCQ questions in this JSON format: [{question, options[], answer}]".
